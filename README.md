# SADE ADU — Sitio web

## Descripción del proyecto

Sitio web dedicado a presentar la trayectoria artística de **Sade Adu** y el recorrido musical de la banda Sade. El proyecto reúne información sobre su biografía, evolución artística, discografía, identidad visual, giras y legado.

La propuesta busca ofrecer una experiencia de navegación clara y accesible, mediante contenidos organizados por temáticas y una identidad visual inspirada en la estética minimalista y editorial asociada a la artista.

## Tecnologías utilizadas

- **HTML:** estructura y organización de los contenidos.
- **CSS:** estilos y personalización de la interfaz.
- **JavaScript:** desarrollo de funcionalidades interactivas.
- **Bootstrap:**  framework CSS utilizado para la organización de los contenidos, los componentes de navegación y la adaptación responsive. También se utilizó su biblioteca JavaScript para implementar componentes interactivos, como los menús desplegables y las ventanas modales.
- **Google Fonts:** tipografías Cormorant Garamond y DM Sans.

## Principales funcionalidades

- **Navegación por secciones:** menú principal con enlaces y categorías desplegables para recorrer las distintas páginas del sitio.
- **Diseño responsive:** adaptación de los contenidos a diferentes tamaños de pantalla mediante Bootstrap.
- **Línea de tiempo interactiva:** permite explorar acontecimientos importantes de la trayectoria de Sade y consultar información ampliada mediante ventanas emergentes.
- **Galería de discografía:** permite seleccionar las portadas de los álbumes para consultar información sobre cada producción mediante ventanas modales de Bootstrap.
- **Formulario de contacto:** permite completar un mensaje y cuenta con validaciones desarrolladas con JavaScript.

## Uso de Inteligencia Artificial

Se utilizaron ChatGPT y Claude como herramientas de consulta y apoyo durante las etapas de investigación, organización de contenidos, diagramación, diseño y desarrollo técnico, así como en la redacción y revisión de la documentación.

La IA se empleó para recopilar información y fuentes, explorar propuestas visuales, comprender e implementar recursos de Bootstrap y JavaScript, y detectar y corregir errores. Las sugerencias fueron revisadas, y tomamos decisiones sobre qué cambios incorporar según los objetivos del proyecto.
